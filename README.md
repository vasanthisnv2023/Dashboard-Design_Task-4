# Task 4: Dashboard Design using Power BI

## Project Overview

This project was developed as part of a Data Analyst Internship Task. The objective was to design an interactive dashboard that helps business stakeholders analyze sales performance, profitability, and growth trends using Power BI.

## Tools Used

* Microsoft Power BI
* Microsoft Excel
* Canva AI (Presentation Design)
* GitHub

## Dataset

Sample Superstore Dataset

The dataset contains information related to:

* Orders
* Sales
* Profit
* Quantity
* Product Categories
* Customer Segments
* Regions

## Dashboard KPIs

The dashboard includes the following Key Performance Indicators (KPIs):

* Total Sales
* Total Profit
* Total Orders
* Total Quantity
* Profit Margin %

## Dashboard Visualizations

### 1. KPI Cards

Displays overall business performance metrics.

### 2. Monthly Sales Trend

Line chart showing sales performance over time.

### 3. Sales by Category

Bar chart comparing sales across product categories.

### 4. Sales by Region

Regional sales performance analysis.

### 5. Sales by Customer Segment

Donut chart showing contribution by customer segments.

### 6. Interactive Filters

Users can filter dashboard data using:

* Order Date
* Region
* Category
* Segment

## Key Insights

* Technology category generated the highest sales.
* Consumer segment contributed the largest share of revenue.
* Sales performance varied across regions.
* Interactive filtering enables detailed business analysis.

## Business Recommendations

* Focus marketing efforts on high-performing categories.
* Improve sales strategies in low-performing regions.
* Increase inventory availability for top-selling products.
* Use dashboard insights for strategic business decisions.
